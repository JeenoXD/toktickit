## My Reflection
The AI-generated first drafts of my Lab 3 spec documents were a good starting point but required significant refinement to align with the strict constraints of the handout (e.g., no email resets, no user deletion, specific admin safety rules). The most valuable moment was catching the `requesterId` leakage in the API spec; the AI defaulted to Lab 2 patterns, and I had to actively enforce the new authenticated-session paradigm. The auth migration itself also taught a real git-hygiene lesson: an untracked migration file and untracked auth source files survived a `git reset --hard` only by luck, since the reset can't remove what was never committed, and I had to verify actual database state with `prisma migrate status` rather than assume the working tree told the whole story.
